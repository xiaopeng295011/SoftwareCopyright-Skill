## 使用

在可运行项目环境中准备 Python 3.10+，全局安装并实际检查 OfficeCLI **1.0.151**；官方安装脚本可能安装新版，必须再次核对版本，不能仅凭安装完成继续。
Windows 原生分页复核需要安装 Microsoft Word；WPS应额外打开复核中文字体与页码。Linux/macOS的结构校验和预览不能代替Word实际分页。
自动截图需要全局 `npm install -g @playwright/cli@0.1.20`，通过 `check_playwright_cli.py` 获取实际绝对路径；浏览器可用与软件页面可运行是额外条件。

```bash
python3 software-copyright-materials/scripts/check_environment.py --out-dir 软件著作权申请资料
python3 software-copyright-materials/scripts/check_playwright_cli.py --out 软件著作权申请资料/截图工具检查.json
python3 -m unittest discover -s software-copyright-materials/tests -v
```

实际申请按照 SKILL.md 顺序：项目分析→业务理解确认→字段与代码选择确认→抽取及手册草稿→截图方式确认→全部Markdown确认→正式Word/TXT。
不能将 tests 中的模拟确认复制到真实申请；真实登记字段、源码选择及最终草稿仍须人工确认。
正式DOCX生成完成后逐个执行 OfficeCLI validate、issues、stats --page-count 和 screenshot。前后30页模式分别应为30页；中文字体、页眉页码、图片清晰度须在Word/WPS复核。
OfficeCLI缺失时使用保留确认门禁的 `--txt-only` 输出TXT；不使用旧引擎冒充迁移测试通过。
